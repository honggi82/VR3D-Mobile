Quadrant 3 · Unknown knowns

화면과 운영의 실제 기대

시각 방향

A 몰입형. 사진이 전체 화면의 주인공이며 보관함·각도·중앙 맞춤만 작게 노출한다.

사용자

국내외 공개 사용자. 웹과 앱은 한국어·영어를 기기 언어에 맞춰 제공한다.

PC 운영자 경험

명령줄이 아니라 Tkinter 데스크톱 GUI에서 서버·터널·대기열·GPU·V3·자동 삭제·로그를 관리한다.

완료의 모습

웹에서 실제 사진을 처리해 .vr3d를 받고, Android 10+ 기기에서 세로·가로 모두 중앙 보정 후 부드럽게 상하좌우 시점을 바꾼다.

보관함

여러 패키지를 로컬에 보관하고 삭제할 수 있다. 앱은 주변 시점만 디코딩해 메모리를 제한한다.

Quadrant 4 · Unknown unknowns

블라인드스폿과 처리 상태

V3의 명시적 파일 검사 API가 확인되지 않음 OPEN

V3 실시간 보호 실행을 서버 시작 조건으로 삼고 추가 로컬 검사 결과까지 요구한다. 구현 중 무해 파일로 결과 코드가 검증되지 않으면 공개 업로드는 켜지지 않는다.

근거: 설치된 V3IS90 실행 파일·서명 확인, 공식 도움말과 탐색기 동사에 개별 검사 CLI 없음.
Quick Tunnel은 고정 주소·가동 보장이 없음 결정됨

endpoint.json을 갱신하고 웹은 서버 오프라인을 명시한다. 테스트·소규모 운영임을 UI에 표시한다.

익명 사진은 바이러스 외 내용 위험도 있음 안전 규칙

로컬 콘텐츠 안전 게이트에서 위험 사진을 차단하고, 차단 파일·썸네일은 즉시 제거한다. 로그에는 사유 코드만 남긴다.

Android Studio와 cloudflared 미설치 OPEN

공식 배포본 설치 또는 위치 확인이 필요하다. Android SDK 34~36과 build-tools는 이미 존재한다.

GitHub 인증 만료 OPEN

로컬 구현에는 영향이 없고, 저장소 생성·Pages 게시 직전에 honggi82 계정 재인증과 게시 승인이 필요하다.

실제 센서 기기 검증 OPEN

에뮬레이터만으로 pitch·roll 체감을 검증할 수 없다. APK 빌드 후 Android 10+ 실기기 연결이 필요하다.

단일 사진의 가려진 배경은 원래 존재하지 않음 SHARP EDGE

±12°/±8° 제한, 깊이 엣지 팽창, z-buffer, 홀 복원과 가장자리 안전 크롭으로 완화하지만 실제 3D 스캔과 같지는 않다.

Tweakable build plan

조정 가능성이 높은 것부터

1. 시점 합성 품질

2D forward splat, 깊이 우선순위, 홀 복원, 안전 크롭을 동일 사진에서 비교한다. ±12°/±8°는 그대로 두고 강도만 조정 가능하게 한다.

검증: 중앙·네 모서리·최대 각도 9시점 골든 이미지

2. 안전 게이트

형식·크기·V3 상태·추가 백신·재인코딩·콘텐츠 안전을 순서대로 강제한다. 하나라도 불명확하면 처리하지 않는다.

검증: 위장 확장자, 이미지 폭탄, 손상 파일, 차단 콘텐츠, 백신 꺼짐

3. 몰입형 상호작용

센서 저역통과 필터와 인접 시점 보간 속도를 실기기에서 조정한다. 회전 시 축 변환과 중앙 재보정을 우선한다.

검증: 세로↔가로 회전, 센서 미탑재 폴백, 60초 메모리 안정성

4. 공개 연결

Tkinter가 서버·Quick Tunnel·endpoint.json 상태를 하나의 상태 머신으로 관리한다.

검증: PC 오프라인, 터널 재시작, 주소 변경, 만료 GitHub 인증

5. 기계적 구현

FastAPI 서버, 24시간 정리 작업, .vr3d 스키마, 다국어 GitHub Pages, Kotlin Android 앱, Gradle 프로젝트와 디버그 APK를 구성한다.

검증: 단위·통합 테스트, Python py_compile, Android lint/test, APK 설치

6. 기준선 비교와 전달

VR3D_v1은 그대로 유지하고 같은 이미지에서 기존 좌우 DIBR와 새 중앙 수평 시점을 비교한다. 문서와 원클릭 실행기를 제공한다.

검증: 원본 미변경, 결과 해시·manifest, 한국어 인코딩 점검
